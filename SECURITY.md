# Security

## Reporting a problem

If you find a security problem in Solam, please don't post the details publicly. Write to salam0support@gmail.com with what you found and how to repeat it. Please don't access other people's accounts or data while testing.

## Getting Solam safely

Only download Solam from:

- [the official website](https://v1sion0coder.github.io/solam/)
- [the releases on this page](https://github.com/v1sion0coder/solam/releases/latest)

Solam is free. If someone asks you to pay for the app or the installer, it isn't from us.

## Checking your download

Each release lists the SHA-256 fingerprint of the installer. In PowerShell, run this in your downloads folder:

```
Get-FileHash Solam-Setup.exe
```

If the result doesn't match the release, don't run the file.

## Supported versions

Only the newest version gets fixes. Solam for Windows updates itself.
